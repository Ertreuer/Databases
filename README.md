# Custom Game Databases 🎮

Welcome to my personal collection of custom, edited databases for various simulation games. The main goal of this repository is to add realism and up-to-date rosters to the games I play, making them available for anyone else in the community looking for a more authentic experience.

## 🚀 Current Databases

### 1. MobaGM 2026 Pro Roster Database
A fully updated, realistic 2026 league file for [MobaGM](https://mobagm.com/). It formats the major global League of Legends esports regions into a comprehensive sandbox, putting you in the shoes of a General Manager.

*   **File Format:** `.json`
*   **Target Game:** MobaGM (ZenGM Legacy)
*   **Roster Year:** 2026 Season

#### 📋 What's Inside?
*   **Complete Regional Leagues:** Features all current tier-1 pro teams across major global regions:
    *   **LCK** (Korea)
    *   **LPL** (China)
    *   **LEC** (EMEA)
    *   **LCS** (North America)
    *   **LCP** (Asia-Pacific)
    *   **CBLOL** (Brazil)
*   **Active Pro Players:** Includes all real-world active pro players assigned to these regions.
*   **Ultimate Free Agency Sandbox:** Every single pro player is currently set up as a **Free Agent**. This allows you to launch a completely custom league, run an organic fantasy draft, or build a powerhouse team from scratch using real 2026 talent right from Day 1.

## 🛠️ How to Use

To import these databases into your game, follow these simple steps:

1.  Navigate to the database file you want in this repository (e.g., `LoL_2026_Ertreuers_Version.json`).
2.  Click on the file, then click the **Download raw file** button (or right-click "Raw" and select *Save Link As...*).
3.  Open https://mobagm.com/ in your browser.
4.  When creating a new league, look for the **Upload Game Data JSON* option.
5.  Select the downloaded `.json` file and initialize your league.
